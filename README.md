# 🎓 Student Performance Prediction Using Machine Learning

## 📌 Project Overview
This project aims to predict student performance based on academic and personal factors using **Machine Learning**. By analyzing datasets of students, the model categorizes them into different performance levels, providing valuable insights for educators and institutions.

## 🚀 Key Features
- **Predicts Student Performance**: Classifies students as **Good, Average, or Poor**.
- **Data-Driven Analysis**: Identifies key academic and behavioral factors affecting performance.
- **Machine Learning Implementation**: Uses **Random Forest Classifier** for prediction.
- **Performance Evaluation**: Analyzes accuracy, confusion matrix, and ROC-AUC curve.

## 📂 Dataset Information
The project uses datasets containing student academic records, such as:
- **Grades (G1, G2, G3)**
- **Study time, Attendance, Failures**
- **Family Support, Internet Access, etc.**

## 🏗 Project Workflow
1️⃣ **Data Loading**: Load student performance datasets from CSV files.
2️⃣ **Data Preprocessing**: Handle missing values, encode categorical variables, and normalize numerical data.
3️⃣ **Model Training**: Train a **Random Forest Classifier** to predict student performance.
4️⃣ **Evaluation**: Measure accuracy, generate a classification report, and plot confusion matrix & ROC-AUC curve.
5️⃣ **Prediction & Interpretation**: Provide performance labels based on model predictions.

## 🛠 Technologies & Tools

- **Machine Learning (Scikit-Learn, Pandas, NumPy)**
